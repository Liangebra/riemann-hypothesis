## 1. The actual uniform-in-q,d rank bound

[IsAlgClosureRat.lean:1844–1950](https://github.com/Liangebra/riemann-hypothesis/blob/be5528a02f46de803a113ccc224659f32f3acdc0/src/Development/AutomorphicArithmetic/AutomorphicVarieties/QuadraticExtensions/IsAlgClosureRat.lean#L1844-L1950) contains the exact provider for TwoIn. The theorem towerTwo first uses abRk at the fixed field data withI M, and obtains g BEFORE introducing q,d. It then chooses

    R(M)=4(g+6 deg M).

The rank over base2(M,q,d) is bounded by R(M) in baseRk, and genLE_of_abRk transports that bound to every presentation of the base field. twoIn chooses that R before the auxiliary prime pair and applies aBound_of_isTower with precisely that R. No choice of a rank after q,d or maximum over infinitely many pairs is involved.

The intermediate Published.FerreroWashington interface is [PublishedTheorems/FerreroWashington.lean:51–55](https://github.com/Liangebra/riemann-hypothesis/blob/be5528a02f46de803a113ccc224659f32f3acdc0/src/Development/AutomorphicArithmetic/AutomorphicVarieties/PublishedTheorems/FerreroWashington.lean#L51-L55): for a fixed abelian K containing the specified roots of unity, class group quotients by l-th powers in all cyclotomic layers have cardinality bounded by l^r with r chosen before the layer and its presentation. It is a uniform rank consequence, not the full usual Iwasawa invariant statement. [FerreroWashington.lean:1414–1515](https://github.com/Liangebra/riemann-hypothesis/blob/be5528a02f46de803a113ccc224659f32f3acdc0/src/Development/AutomorphicArithmetic/AutomorphicVarieties/GaloisLibrary/FerreroWashingtonIndex/FerreroWashington.lean#L1414-L1515) actually proves this interface: embed the fixed K and all its layers in full cyclotomic fields with fixed prime-to-l conductor f and bounded relative degrees; obtain B,n0 for the full cyclotomic fields via stickH, core, ambCyc and the sign/reflection arguments (separate branches l=2 and odd l). Then use desc to bound the class group quotient in the subfield by D*l^n0*B. The final witness r=D*l^n0*B is intentionally much larger than log_l of that number. The deep Stickelberger, ambiguous class group, nilpotence/memZ, reflection and sign providers are not independently validated in this note. There is an actual theorem body, not an assumption of FerreroWashington in Main.

The passage to the infinite cyclotomic kernel is also explicit. [IsAlgClosureRat.lean:1231–1315](https://github.com/Liangebra/riemann-hypothesis/blob/be5528a02f46de803a113ccc224659f32f3acdc0/src/Development/AutomorphicArithmetic/AutomorphicVarieties/QuadraticExtensions/IsAlgClosureRat.lean#L1231-L1315) defines an ascending family S_n of characters restricted from finite congruence levels; xdualExt supplies extension of each character to some level, and restrMem preserves the conditions. If all S_n have cardinality <=l^r, then their union does too: any finite subset of the union lies in a single sufficiently large S_n, and a set with >l^r elements would contain a finite subset of size l^r+1. This avoids assuming the inverse limit of arbitrary finite rank groups has bounded rank without a compatible exhaustion. The xdualExt arithmetic/topological extension provider remains to inspect.

[IsAlgClosureRat.lean:889–918](https://github.com/Liangebra/riemann-hypothesis/blob/be5528a02f46de803a113ccc224659f32f3acdc0/src/Development/AutomorphicArithmetic/AutomorphicVarieties/QuadraticExtensions/IsAlgClosureRat.lean#L889-L918) converts a bound on D[l] for the l-primary torsion module D into generation of Hom_R(D,Q_l/Z_l): embed D in (Q_l/Z_l)^r using separation on D[l], extend linear functionals using injectivity of Q_l/Z_l, and use End_R(Q_l/Z_l)=R to express them as linear combinations of the r coordinate functionals. [IsAlgClosureRat.lean:923–988](https://github.com/Liangebra/riemann-hypothesis/blob/be5528a02f46de803a113ccc224659f32f3acdc0/src/Development/AutomorphicArithmetic/AutomorphicVarieties/QuadraticExtensions/IsAlgClosureRat.lean#L923-L988) supplies the actual finite mod-l character bound for Dinf: any locally constant function on the compact cyclotomic kernel has finite image, so Dinf is l-primary torsion, and its l-torsion injects into XDual with ZMod l coefficients. ## 2. Why the auxiliary primes only contribute 6 deg M

Let V be the cyclotomic kernel over the fixed withI(M). The equality V=abU(M) intersect ker(cycZ_2) is proved in [IsAlgClosureRat.lean:1563–1593](https://github.com/Liangebra/riemann-hypothesis/blob/be5528a02f46de803a113ccc224659f32f3acdc0/src/Development/AutomorphicArithmetic/AutomorphicVarieties/QuadraticExtensions/IsAlgClosureRat.lean#L1563-L1593). For p=q with q=3 mod 8, v_2(q²-1)=3; for p=d with d=7 mod 16, v_2(d²-1)=4. [IsAlgClosureRat.lean:1455–1509](https://github.com/Liangebra/riemann-hypothesis/blob/be5528a02f46de803a113ccc224659f32f3acdc0/src/Development/AutomorphicArithmetic/AutomorphicVarieties/QuadraticExtensions/IsAlgClosureRat.lean#L1455-L1509) checks those valuations explicitly. A closed subgroup H of Z_2^× containing p consequently has index <=2 or <=4 respectively: the powers of p² generate the principal subgroup at the corresponding depth, and p contributes the nontrivial coset modulo that depth. The source uses index_closed_dyadic_subgroup (1415ff), rather than claiming that p generates all of Z_2^×.

[IsAlgClosureRat.lean:1519–1549](https://github.com/Liangebra/riemann-hypothesis/blob/be5528a02f46de803a113ccc224659f32f3acdc0/src/Development/AutomorphicArithmetic/AutomorphicVarieties/QuadraticExtensions/IsAlgClosureRat.lean#L1519-L1549) constructs the arithmetic Frobenius in the decomposition subgroup, checks its cyclotomic character equals p by congruences on primitive 2^n-th roots for every n, then obtains [G_Q:ker(cycZ_2) Dec_p]<=2 or <=4 via the closed image. [IsAlgClosureRat.lean:1563–1593](https://github.com/Liangebra/riemann-hypothesis/blob/be5528a02f46de803a113ccc224659f32f3acdc0/src/Development/AutomorphicArithmetic/AutomorphicVarieties/QuadraticExtensions/IsAlgClosureRat.lean#L1563-L1593) multiplies by [G_Q:abU(M)]=deg M and uses orbit representatives for valuations. Thus the number of relevant V-orbits is at most 2 deg M at q and 4 deg M at d. The orbit and Frobenius providers are residual checks, but the congruence and index deductions are explicit.

[IsAlgClosureRat.lean:328–405](https://github.com/Liangebra/riemann-hypothesis/blob/be5528a02f46de803a113ccc224659f32f3acdc0/src/Development/AutomorphicArithmetic/AutomorphicVarieties/QuadraticExtensions/IsAlgClosureRat.lean#L328-L405) adds ramification at a prime p different from l. For each orbit of valuations above p, tameGen gives a test element of inertia whose value detects a continuous homomorphism to Z/l. Because inertia at those primes is contained in V (ineTwo is supplied using coprimality), a character is defined on these elements. The evaluation map to (Z/l)^T has kernel equal to the old unramified-outside-N character space: agreement on representatives extends to all inertia by conjugacy invariance of additive characters. An injection into the product of evaluations and old characters is explicitly constructed using a choice of a representative in each evaluation fibre. Thus allowing p multiplies the character bound by at most l^#T. At l=2 the two steps give 2^(g+2deg M+4deg M).

Two quadratic enlargements then square the bound twice. [QuadStep.lean:397–472](https://github.com/Liangebra/riemann-hypothesis/blob/be5528a02f46de803a113ccc224659f32f3acdc0/src/Development/AutomorphicArithmetic/AutomorphicVarieties/QuadraticExtensions/QuadStep.lean#L397-L472) checks open subgroups of relative index dividing 2, conjugation stability of the allowed inertia set, and containment of inertia outside the allowed primes in the smaller group. In index 2 the involution on the character module has (1+sigma)^2=0 in characteristic 2. Its image lies in its kernel; the invariant character bound comes from invTwo, which handles the extension obstruction rather than assuming every invariant extends. sqZero therefore bounds the full cardinal by the square of the invariant bound. The two steps give exponent 4(g+6deg M), exactly the chosen R(M). The invTwo proof and tameGen provider merit deeper inspection, as does the equality linking the chosen character space with class group quotients (levelRk).

Finally, [IsAlgClosureRat.lean:1919–1935](https://github.com/Liangebra/riemann-hypothesis/blob/be5528a02f46de803a113ccc224659f32f3acdc0/src/Development/AutomorphicArithmetic/AutomorphicVarieties/QuadraticExtensions/IsAlgClosureRat.lean#L1919-L1935) constructs TwoBase with degree <=8deg M and an embedding into the conductor 4 M.m q d cyclotomic field. Each target composite field E at level e is compared with a layer of this base field of index m<=e+2; compIndex supplies relative degree dividing 2 and [IsAlgClosureRat.lean:1805–1827](https://github.com/Liangebra/riemann-hypothesis/blob/be5528a02f46de803a113ccc224659f32f3acdc0/src/Development/AutomorphicArithmetic/AutomorphicVarieties/QuadraticExtensions/IsAlgClosureRat.lean#L1805-L1827) gives shaInv(E,2,k)<=1+shaInv(L_m,2,k). The +1 arises from restriction kernel control, not from unconditional injectivity of restriction in degree 2. Its provider kerTwo and the actual field comparison compIndex remain residual arithmetic audits.

## 3. Descent from Sha to one fixed endomorphism

[ExistsDescends.lean:1383–1420](https://github.com/Liangebra/riemann-hypothesis/blob/be5528a02f46de803a113ccc224659f32f3acdc0/src/Development/AutomorphicArithmetic/AutomorphicVarieties/NumberFieldTowers/ExistsDescends.lean#L1383-L1420) proves exists_descends by choosing a generator gamma of the cyclotomic image over L0 once, before all positive twists e and layers m. Its step0 embeds each L_m in the same closure, invokes layerUniq to identify its subgroup, and layerGen to choose gamma^(l^m) as topological generator of the new cyclotomic image. The resulting length identity is

    shaInv(L_m,l,e)=length coker(g_e^(l^m)-1),

where g_e is the endomorphism xTw on the fixed algebraic dual of Dinf, not a new endomorphism chosen at every level.

[ExistsDescends.lean:917–981](https://github.com/Liangebra/riemann-hypothesis/blob/be5528a02f46de803a113ccc224659f32f3acdc0/src/Development/AutomorphicArithmetic/AutomorphicVarieties/NumberFieldTowers/ExistsDescends.lean#L917-L981) explicitly proves surjectivity of the restriction from Sha to the equivariant character group of the infinite cyclotomic kernel. On that kernel the coefficient action is trivial. For an equivariant locally constant homomorphism satisfying inertia and local decomposition conditions, extCocycle extends it to a global cocycle, decCob gives a local primitive at each l-adic place using e!=0, and away from l the inertia condition gives zero on the appropriate inertia. shaInfl then realizes the class in the restricted Galois cohomology. The equality of restrictions is independent of the chosen global coboundary because the cyclotomic kernel acts trivially. The complementary injectivity is via resInfInj. The specific proofs of extCocycle, decCob and resInfInj are still substantial and must not be glossed over as a general inflation-restriction isomorphism.

[ExistsDescends.lean:1073–1207](https://github.com/Liangebra/riemann-hypothesis/blob/be5528a02f46de803a113ccc224659f32f3acdc0/src/Development/AutomorphicArithmetic/AutomorphicVarieties/NumberFieldTowers/ExistsDescends.lean#L1073-L1207) transports this character module along the actual field embeddings into the fixed base Galois group; the subgroup equality of cyclotomic kernels is a hypothesis established by layerUniq in the caller. The proof checks the equivariance formula using conjugation by g^{-1} and chi^{-e} and constructs a linear equivalence by actual restriction, with injectivity and surjectivity from the preceding providers.

[ExistsDescends.lean:1313–1364](https://github.com/Liangebra/riemann-hypothesis/blob/be5528a02f46de803a113ccc224659f32f3acdc0/src/Development/AutomorphicArithmetic/AutomorphicVarieties/NumberFieldTowers/ExistsDescends.lean#L1313-L1364) identifies invariants under the entire layer with ker(dTw(gamma)-1), also using gamma^{-1}. Invariance under a topological generator of the cyclotomic image alone would not be enough without control of the kernel. Here each phi is l-power torsion and fixed by a sufficiently deep congruence subgroup (dinfTors and dinfNil); hence approximate the cyclotomic image of any v by an integer power of gamma so that the discrepancy belongs to this subgroup. This proves invariance under v. At [ExistsDescends.lean:313–327](https://github.com/Liangebra/riemann-hypothesis/blob/be5528a02f46de803a113ccc224659f32f3acdc0/src/Development/AutomorphicArithmetic/AutomorphicVarieties/NumberFieldTowers/ExistsDescends.lean#L313-L327) the dual of this kernel is the cokernel of the transposed operator by exactness of Hom(-,Q_l/Z_l), and lenDual proves equality of lengths. The source uses the inverse generator to match the action xTw; it does not conflate the action with its contragredient. No integral perfect PT pairing is needed here. Residual: independently audit dinfNil, extension and local coboundary providers, cokerDual's injective target and length lemma.

## 4. Matrix estimate works even when the fixed module has torsion

[ABoundOfDescends.lean:627–663](https://github.com/Liangebra/riemann-hypothesis/blob/be5528a02f46de803a113ccc224659f32f3acdc0/src/Development/AutomorphicArithmetic/AutomorphicVarieties/AdditiveValuationNorms/ABoundOfDescends.lean#L627-L663) starts with a surjection pi:R^R->X (R as ring here means Z_l; generator count is the integer R in source). To avoid ambiguity denote the count by r. Lift the images g(pi(e_i)) to columns of an r x r matrix S over Z_l. Then pi S=g pi. For every scalar b, pi induces a surjection

    coker(b S-I) -> coker(b g-I).

Hence length coker(b g-I) <= v_l det(b S-I), with infinite valuation when the determinant is zero. The equality for the free square matrix is length_cokernel_eq_addVal_det. The choice of S precedes b. This does not assume that X is free, nor that g is diagonalizable.

[ABoundOfDescends.lean:93–139](https://github.com/Liangebra/riemann-hypothesis/blob/be5528a02f46de803a113ccc224659f32f3acdc0/src/Development/AutomorphicArithmetic/AutomorphicVarieties/AdditiveValuationNorms/ABoundOfDescends.lean#L93-L139) factors det(bS-I) over the p-adic algebraic closure as product_i (b z_i-1), using characteristic polynomial roots with multiplicity. The crucial point is that the centre for an eigenvalue need NOT be an actual solution of u^(l^j e) z_i=1. [ABoundOfDescends.lean:179–239](https://github.com/Liangebra/riemann-hypothesis/blob/be5528a02f46de803a113ccc224659f32f3acdc0/src/Development/AutomorphicArithmetic/AutomorphicVarieties/AdditiveValuationNorms/ABoundOfDescends.lean#L179-L239) proves for any z in the algebraic closure that there exists s in Z_l such that for every nonnegative integer e,

    l^(-(j+c)) ||s-e|| <= ||u^(l^j e) z-1||.

Proof: if a,b are p-adic units, ||a-b|| <= max(||az-1||,||bz-1||). For ||z||>=1 use the ultrametric inequality on their difference; for ||z||<1 the right terms have norm 1. With the exact LTE distance relation ||u^(l^j a)-u^(l^j b)||=l^(-(j+c))||a-b||, the closed balls centered at e with radii l^(j+c)||u^(l^j e)z-1|| have pairwise compatible radii. Any finite subfamily contains the centre of a smallest ball in every other ball. Compactness of Z_l gives a common s. This is the actual Helly argument [ABoundOfDescends.lean:148–173](https://github.com/Liangebra/riemann-hypothesis/blob/be5528a02f46de803a113ccc224659f32f3acdc0/src/Development/AutomorphicArithmetic/AutomorphicVarieties/AdditiveValuationNorms/ABoundOfDescends.lean#L148-L173); it does not require a p-adic logarithm of z or assume an algebraic closure is compact. Taking the product of the eigenvalue inequalities proves detBound [ABoundOfDescends.lean:246–273](https://github.com/Liangebra/riemann-hypothesis/blob/be5528a02f46de803a113ccc224659f32f3acdc0/src/Development/AutomorphicArithmetic/AutomorphicVarieties/AdditiveValuationNorms/ABoundOfDescends.lean#L246-L273). The norm-to-extended-valuation conversion and the precise IsLevel hypotheses of lteNorm remain separate providers.

## 5. Linear growth in the tower level

[ABoundOfDescends.lean:570–619](https://github.com/Liangebra/riemann-hypothesis/blob/be5528a02f46de803a113ccc224659f32f3acdc0/src/Development/AutomorphicArithmetic/AutomorphicVarieties/AdditiveValuationNorms/ABoundOfDescends.lean#L570-L619) proves the growth estimate for any finitely generated Z_l-module X generated by r elements and a mod-l unipotent operator g. Set j0=floor(log_l r)+3 as in jZero. The nilpotence bound on g-I in X/lX (nilLen, unipPow) first gives g^(l^k)-I mapping X into lX at k=floor(log_l r)+1 via the characteristic-l Frobenius identity for the powers of one endomorphism. One more powering ensures the image lies in l²X, and this property persists. The conservative j0 is large enough even at l=2.

The step [ABoundOfDescends.lean:344–413](https://github.com/Liangebra/riemann-hypothesis/blob/be5528a02f46de803a113ccc224659f32f3acdc0/src/Development/AutomorphicArithmetic/AutomorphicVarieties/AdditiveValuationNorms/ABoundOfDescends.lean#L344-L413) is particularly robust in the presence of torsion. For w with (w-I)X contained in l²X, let A=sum_{i=0}^{l-1} w^i. For each x, Ax=l x modulo l²X. Therefore

    lX subset im A + l(lX).

Nakayama's lemma on the submodule lX (or its image in X/im A) gives lX subset im A, without dividing by l or requiring w-I to be divisible by l as a map with a chosen linear quotient. Thus length coker A <= length X/lX <= r. The composition inequality and (w-I)A=w^l-I give

    length coker(w^l-I) <= length coker(w-I)+r.

Iterate above j0; below j0 use image containment from the geometric sum factorization. This proves the stated growth bound even if some lengths are top, without subtracting infinity. The twist preserves mod-l unipotence since u^e=1 mod l. Combine the fixed-level matrix estimate with growth to get centres s_i chosen independently of e,m, and the first ABound; use the previously audited Sha<=V at reference level j0 for its second part. This establishes why the earlier finite-to-integral length estimate is actually consumed at a fixed reference layer.

## 6. Common window selection is an elementary separate lemma

[HVCore.lean:667–773](https://github.com/Liangebra/riemann-hypothesis/blob/be5528a02f46de803a113ccc224659f32f3acdc0/src/Development/AutomorphicArithmetic/AutomorphicVarieties/ModularityArgument/ThresholdArguments/DenseThresholdCases/HVCore.lean#L667-L773) proves window1 by induction on the number R of exceptional values. For a finite set T of real numbers, B>=1, U>0, |T|<=R, find y satisfying U/(2^(R+2) B^R)<=y and 2y<=U, such that for u in [y,2y], a in T and a<=u imply Ba<=u. If there is an a in (U/(2B),U], decrease U to U/(2B) and erase that a, so the discarded a lies strictly above the new interval. If no such a exists take y=U/2: any a<=u<=U is <=U/(2B), hence Ba<=u. The base case R=0 is immediate. No asymptotic approximation is involved.

Apply this with U=log X, B=Ct/eta, and a=log e/Ct for e in the exceptional set. Set Y=exp y and J=2^(R+2)(Ct/eta)^R. Then

    X^(1/J)<=Y, Y²<=X,
    for all x in [Y,Y²], e in Exc: e<=x^Ct implies e<=x^eta.

The proof separately handles e=0 before using log inequalities. [HVCore.lean:349–405](https://github.com/Liangebra/riemann-hypothesis/blob/be5528a02f46de803a113ccc224659f32f3acdc0/src/Development/AutomorphicArithmetic/AutomorphicVarieties/ModularityArgument/ThresholdArguments/DenseThresholdCases/HVCore.lean#L349-L405) chooses the dyadic threshold x0 before e,t,X,q,d,L0, using the degree bound 8 deg M, the conductor embedding and log(qd)<=X^(eps/(4J)) to get a uniform reference-layer discriminant estimate at x>=X^(1/J). It uses TwoBase's +1 correction and point2, not Lemma K at the moving high layer. [HVCore.lean:610–657](https://github.com/Liangebra/riemann-hypothesis/blob/be5528a02f46de803a113ccc224659f32f3acdc0/src/Development/AutomorphicArithmetic/AutomorphicVarieties/ModularityArgument/ThresholdArguments/DenseThresholdCases/HVCore.lean#L610-L657) treats the fixed odd base via actual field equivalences abiso and layeriso, transporting shaInv to any presentation. Finally [HVCore.lean:847–871](https://github.com/Liangebra/riemann-hypothesis/blob/be5528a02f46de803a113ccc224659f32f3acdc0/src/Development/AutomorphicArithmetic/AutomorphicVarieties/ModularityArgument/ThresholdArguments/DenseThresholdCases/HVCore.lean#L847-L871) takes the union of the exceptional sets, whose cardinality is <=R0+sum R_l, applies the same window, and restricts Good to each subset. Thus a SINGLE common window is obtained, not separate windows with possibly empty intersection. The detailed point2, exc, vvat, layerdisc and subsequent analytic/nonvanishing consumers still need audit.
